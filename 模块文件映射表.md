**QueryTemplate实体结构**:
```java
public class QueryTemplate extends BaseEntity {
    private Long id;                  // 模板ID
    private String templateName;       // 模板名称
    private String queryType;          // 查询类型 (birth-year/mileage/travel-time)
    private String rangesJson;         // 区间配置JSON
    private Integer gender;             // 性别筛选
    private String description;         // 模板描述
}
```
